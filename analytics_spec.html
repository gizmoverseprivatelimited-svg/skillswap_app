🔍 2. Detailed Event Specifications & Code
1. Screen View Automatic Navigation Tracking
app/_layout.tsx
Tracks screen navigation changes seamlessly using Expo Router paths, matching official React Native Firebase recommendations with a route name ref to avoid redundant events.
Parameter Type Required Description Sample Value
screen_name string Yes Current route pathname "Home", "(tabs)/home", "class/102"
screen_class string Optional Screen class or category "Home", "class/[id]"
// Automatic Screen View in Root Layout Nav const routeNameRef = React.useRef<string | null>(null); useEffect(() => { const currentRouteName = pathname || (segments.length > 0 ? segments.join('/') : 'Home'); if (routeNameRef.current !== currentRouteName) { routeNameRef.current = currentRouteName; logScreenView(currentRouteName); } }, [pathname, segments]);
2. sign_up User Registration
providers/auth.tsx
Logged immediately after a new user account is successfully provisioned via email, Google OAuth, or phone OTP.
Parameter Type Required Description Sample Values
method string Yes Registration provider used "email", "google", "otp"
// Logged in signUp / OAuth registration await analytics().logSignUp({ method: 'email' });
3. login User Authentication
providers/auth.tsx
Fired when an existing user authenticates into the application.
Parameter Type Required Description Sample Values
method string Yes Authentication mechanism "email", "google", "otp"
// Logged in signIn / signInWithOAuth / signInWithOtp await analytics().logLogin({ method: 'google' });
4. course_view Course / Class Page View
app/class/[id].tsx
Fires automatically when a user opens and views any class or course detail page.
Parameter Type Required Description Sample Values
course_id string Yes Unique identifier of the course "cls-17290123"
course_name string Yes Human-readable course title "Photoshop Basics", "UI/UX Design Masterclass"
// Logged in ClassDetailScreen useEffect await analytics().logEvent('course_view', { course_id: cls.id, course_name: cls.title, });
5. course_purchase Course Purchase & Enrollment
providers/classes.tsx
Centralized in enrollInClass so all enrollment entry points (class screen, user profile, skill modal) reliably log revenue/credit metrics.
Parameter Type Required Description Sample Values
course_id string Yes Course identifier "cls-17290123"
value number Yes Cost or credits deducted 15, 250, 0 (free)
currency string Yes Currency ISO code "INR"
// Logged in enrollInClass when enrollment is confirmed await analytics().logEvent('course_purchase', { course_id: cls.id, value: cost, currency: 'INR', });
6. skill_swap_request Skill Swap Request Submitted
components/SkillSwapRequestModal.tsx
Fired when a user successfully sends a skill swap or learning session request to another user.
Parameter Type Required Description Sample Values
skill_offered string Yes Title of offered skill or 'Credits' "Guitar Basics", "Credits"
skill_wanted string Yes Title of wanted skill or 'Credits' "Web Development", "Credits"
// Logged after submitSwapRequest succeeds await analytics().logEvent('skill_swap_request', { skill_offered: offeredSkill, skill_wanted: wantedSkill, });
👤 3. User Identity & Helper Cheatsheet
User Identity Syncing
Automatically maintains user identification and attributes across sessions:
Method / Property Parameter Description
setUserId(userId) user.id or null Associates all subsequent events with the authenticated user UID; clears on logout.
setUserProperty('user_role', role) 'member' | 'admin' | 'teacher' Enables user segmentation in Firebase Analytics dashboards and audiences.
// Quick-start import from anywhere in the codebase: import analytics, { logCourseView, logCoursePurchase, logSkillSwapRequest } from '@/lib/analytics'; // 1. Typed helper methods: await logCourseView('c123', 'Photoshop Basics'); await logCoursePurchase('c123', 500, 'INR'); await logSkillSwapRequest('Photoshop', 'Video Editing');
